# GeoDash 2.2

**GeoDash 2.2** is a fast, mobile-friendly Geometry Dash–style platformer built entirely in **HTML, CSS, and JavaScript**.  
It includes **7 short levels**, a **level editor**, **player customization**, and full browser support on desktop and mobile.

---

## ⭐ Features

### 🎮 Core Gameplay
- Smooth cube movement  
- Accurate jump physics  
- Ground, platforms, spikes, obstacles  
- Hitbox-accurate collision system  
- Fixed instant-death bug while standing on blocks  

### 🗺️ Levels
- 7 short, fast-paced levels  
- Each designed for quick restarts and consistent timing  

### 🛠️ Level Editor
- Drag-and-drop object placement  
- Blocks, spikes, platforms & more  
- Instant Play mode  
- Save & load custom levels using LocalStorage  
- Place objects directly on ground (bug fixed)

### 👤 Player Customization
- Change cube color  
- Custom icons (optional expansion)  
- Trail color selection  

### 📱 Mobile Support
- Tap-to-jump  
- Optimized UI  
- Smooth 60 FPS gameplay  
- Fully responsive layout
